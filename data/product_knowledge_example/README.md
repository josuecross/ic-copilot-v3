# Product Knowledge Example

This is a committed, non-private example of the `local_knowledge/` folder contract.

Normal product runs use the private `local_knowledge/` folder, not this example, unless a
developer/test command passes this directory explicitly. These files are derived from the
contract fixtures and are intended for validator, CLI, and smoke-test coverage only.

Every command remains a manual-copy suggestion. Nothing in this folder enables Slack posting,
paging, command execution, remediation, or external writes.
